# veda-charts-social-assets

Public image host for VedaCharts social posts (Instagram, Threads, X via Buffer).

- Images are rendered from the VedaCharts brand templates and committed automatically by the daily social run.
- Layout: `YYYY/MM/<slug>.jpg`, 1080×1350.
- Buffer pulls each image from its raw URL when the post publishes, so **don't delete or rename files** until their posts have gone out.
- Nothing private lives here: only finished images that are posted publicly.
